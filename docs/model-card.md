# 모델 카드: survey-ewma-location-scenario-v1

## 예측 대상과 범위

서울 2호선 본선 인접 구간, 출발역·방향별 30분 혼잡률 조사평균을 추정하고 이를 10개 칸에 배분하는 교육용 모델이다. 201~243번 역만 사용한다. 역 코드 증가 방향은 내선, 감소 방향은 외선이며 243↔201에서 순환한다. 성수·신도림 지선 및 별도 운행계통 코드 9001~9003은 제외한다. 좌석 점유율이나 실시간 열차 승객 수와 다르다.

## 학습된 부분

각 키 `station|direction|daytype|time`의 양수 조사값 y를 조사시점 순으로 갱신한다.

`m_t = alpha * y_t + (1-alpha) * m_(t-1)`

첫 유효값을 초기값으로 사용한다. 0·NaN은 미운행 가능성 때문에 제외하며 유효 이력이 전혀 없으면 응답을 거부한다. 각 키의 마지막 관측시점과 누적 관측수를 기록한다. 조사시점 사이 간격은 같지 않으며 현재 모델은 경과일에 따른 가중치를 별도로 추정하지 않는다.

alpha 후보 0.1, 0.25, 0.5, 0.75, 1.0 중 2026-03 조사 MAE가 가장 작은 값을 선택했다. 최종 테스트 2026-06은 후보 선택에 사용하지 않았다. alpha=1.0이 선택돼 최신 유효 조사값을 쓰는 방식과 동일하다. 2026-06 조사 테스트 MAE 3.2165%p는 칸별 값, 일별 실측, 돌발 혼잡 또는 앞으로 도착할 특정 열차에 대한 정확도가 아니다. 기준일은 파일명으로 얻은 스냅샷 식별자이며 실제 수집일시 전체를 뜻하지 않는다.

## 학습하지 않은 칸별 배분

다른 노선에서 환승한 뒤 가까운 승차 호차 집합 T, 해당 방면의 에스컬레이터 접근 호차 집합 A를 사용한다. 출발역명·노선·다음 역 방면이 일치하는 데이터만 선택하고 중복 시설/동일 위치는 호차 단위로 제거한다. 모든 호차/모든 문 값, 방면이 모호한 텍스트, 출입구 번호만 있는 행은 특정 칸에 배정하지 않는다. 본선 이외에서 숫자 10량 가정을 확장하지 않는다.

각 비어 있지 않은 집합 G에 대해 칸 c의 근접도는 `mean(exp(-0.5*(c-k)^2), k in G)`이며 T/A가 모두 있으면 두 근접도를 동일 가중 평균한다. 이 거리는 호차 번호 차이이며 미터 단위 물리적 거리가 아니다.

`factor_c = (1-s) + s * proximity_c / mean(proximity)`

`car_estimate_c = predicted_train_mean * factor_c`

s 기본값 0.2, 허용범위 0~0.3은 **연구 가정**이다. 정답으로 최적화하거나 승객 표본으로 측정하지 않았다. 두 집합이 모두 비면 모든 factor=1. 동일 정원 10칸 가정 아래 칸별 혼잡률 평균은 열차 혼잡률과 같다. s=0 및 s=0.3의 최소·최대는 가정 변화에 따른 민감도 범위이며 신뢰구간이 아니다. 반올림으로 평균에 최대 약 0.001%p 오차가 생길 수 있다.

환승 하차 위치를 혼잡 가중치로 더하지 않았다. 많이 내리는 칸은 오히려 출발 후 혼잡도가 줄 수 있기 때문이다. 현재 모델은 출발 전 재차인원, 칸별 승하차량, 칸 사이 이동을 추정하지 않으므로 인원 보존 기반 동적 운행 시뮬레이터가 아니다. 사용자에게 실측으로 검증되지 않은 시나리오임을 노출해야 한다.

## 사용하지 않은 수집 데이터와 이유

- 월별 환승유입인원: 실제 환승 통로 수요가 아니라 타 호선에서 출발한 사람의 최종 목적지 하차량이다. 칸에 나누면 의미가 달라져 제외.
- 행정동 생활인구·역 승하차량: 승강장 방향·열차·칸별 재차인원과 단위가 다르다. 칸별 정답 없이 보정 계수를 정당하게 학습할 수 없어 이번 모델에서는 사용하지 않음. 앞선 역 승하차량 모델에서도 생활인구의 추가 효과가 일관되지 않았다.
- 안내도 이미지: 실측 호차 위치·거리를 자동 생성할 수 없어 보조 검토에만 사용.
- SK 통계 API: 키 미보유. 문서 예시를 관측 정답으로 사용하지 않음.

공식 지표 정의: https://data.seoul.go.kr/bsp/wgs/dataView/data300View/643.do

## 시간·품질·운영 한계

- at 생략은 한국 현재시각, HH:MM은 한국 오늘 날짜. 자정 00시대의 요일·공휴일은 전날 운행일 기준.
- 공휴일은 holidays KR 캘린더로 판별 후 일요일 패턴으로 대체. 임시공휴일 변경과 운행계획은 별도 업데이트가 필요하다.
- 01:00~05:29는 서비스 범위 밖. 실제 열차 운행 유무를 시간표와 대조하지 않았으므로 범위 안이어도 특정 열차 운행을 보장하지 않는다.
- 현 위치 파일은 2025-03 환승 및 2026-02 에스컬레이터 기준. 공사·통로 변경을 자동 반영하지 않는다.
- 현재 학습 기준일 이하 조회는 거부해 현재 모델을 과거 검증으로 오인하지 않도록 한다. 학습 기준일 이후에도 자료 공개일을 반영한 실시간 재현은 아니다.
- 수집 원본은 조사 평균이므로 시간대별 자료 행 수가 많아도 독립 조사시점은 9개뿐이다. 인접 칸/시간의 상관관계를 고려하지 않은 독립 표본 정확도 주장을 하지 않는다.
- 사고·행사·지연·실시간 유동인구에 반응하지 않는다. 여유 있는 칸 추천의 성공률은 평가하지 못했다.

## 실측 확보 후 교체 계획

관측일시·열차 운행 식별자·역·방향·호차·정원·재차인원·도착 전/출발 후 정의가 있는 타깃을 확보한다. 기준선, 위치 추가, 실제 환승 수요 추가 모델을 같은 시간 분리 표본으로 비교한다. 같은 열차의 칸은 동일 평가 분할에 두고 역 보류 평가도 별도로 한다. 검증 전에는 `car_accuracy=null`, `prediction_kind=unvalidated_car_scenario`를 유지한다.
