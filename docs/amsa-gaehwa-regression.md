# 암사 → 개화 경로 수정 (2026-09-21)

시간표 탐색 전환 후에도 상세 환승 위치 CSV에 석촌 8↔9호선 연결이 없어 해당 경로를 후보로 만들지 못했다. 문 위치 조사에 없는 연결을 환승 불가능으로 취급한 것이 원인이다. 수정 전 08:15 예상시간 우선은 천호·여의도·김포공항에서 변경하는 3회 경로를 반환했다.

[서울시 공식 9호선 3단계 안내](https://mediahub.seoul.go.kr/archives/1209700)는 석촌 8↔9호선 및 올림픽공원 5↔9호선 환승을 명시한다. `datasets/transfer_connections_supplement.json`에 이 연결의 출처를 기록하고, `scripts/prepare_transfers.py`에서 기존 상세 자료와 별도로 양방향 연결을 보완한다. 총 환승 연결은 90개에서 94개가 되었다. 동일 이름이라는 이유만으로 임의 연결을 생성하지 않는다.

이 자료에서 정확한 보행시간과 문 위치는 확인되지 않았으므로, 보행시간은 기존 정책의 **5분 가정**(`time_basis=assumed_5_minutes`), 문 위치는 자료 없음이다. API는 환승 연결의 공식 근거와 보행시간 가정을 구별한다.

또한 예상시간 우선 탐색에서 같은 플랫폼에 먼저 도착했더라도 환승 횟수가 더 많은 상태가 늦게 도착한 적은 환승 상태를 제거하지 않도록 했다. 이후 같은 열차를 탈 수 있으면 최종 도착은 같으므로, 환승 횟수별 탐색 상태를 보존해야 불필요한 추가 변경을 피할 수 있다.

검증된 예상시간 우선 경로:

암사 **8호선 일반** → 석촌 **9호선 급행** → 김포공항 **9호선 일반** → 개화

- 2026-09-21 08:15 및 18:00: 환승/열차 변경 2회.
- 08:15: 09:38 도착, 83분(대기 포함).
- 08:15 환승 최소: 석촌에서 9호선 일반을 타고 개화까지 가는 1회 환승 경로. 약 96분 10초이므로 가장 빠른 경로와는 다르다.
- 시간표 기준은 여전히 2025-09-30 공개본이다. 실제 당일 운행이나 지연을 검증한 결과는 아니다. 다른 출발시각에는 연결 열차에 따라 최적 경로가 달라질 수 있다.

수정 결과는 `artifacts/amsa_gaehwa_regression.json`에 기록했다. 오전·오후 암사→개화, 환승 최소, 올림픽공원 양방향 연결, 같은 도착시각의 불필요한 환승 제거를 회귀 테스트로 추가했다. 전체 백엔드 58개 테스트 통과.

실행 중인 서비스는 배포 또는 재시작하면 버전 해시 변경을 감지해 SQLite 환승 seed와 메모리 경로 그래프를 갱신한다.
